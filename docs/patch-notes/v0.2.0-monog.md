# v0.2.0-monog

Pulido visual y bucle de exploración de [[monog-gdd]].

- Ambiente Toon-Cyber en runtime: niebla violeta, bloom, gradación de color y estrellas ([[art-direction]]).
- Destellos de rareza, golpes de cámara y rayos de luz girando en la revelación del gacha.
- Mascotas chibi con ojos brillantes, mejillas, andador y aro de rareza; saltitos con squish & stretch.
- Mapa vivo: 7 etiquetas de animación para cualquier pieza (giros, flotar, latidos de neón, bombillas, palomas que pasean) ([[world-building]]).
- Caramelos de abuela por todo el mapa con monedas, tickets y gemas ([[economy-systems]]).
- Skill de proyecto `monog-art-direction` para mantener el estilo.
