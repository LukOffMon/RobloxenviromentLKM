# v0.1.0-monog

Primera versión jugable de [[monog-gdd]].

- Gacha de Cajas de Asilo con cinemática, piedad a las 1000 tiradas y Shiny ([[og-catalog]]).
- 10 arquetipos de OG en 6 rarezas, mascotas chibi que siguen al jugador.
- Pensión pasiva con bonus por amigos y pensión offline ([[economy-systems]]).
- «Chanclazo Timing» juzgado por el servidor ([[progression-tree]]).
- Combates por turnos contra rivales NPC ([[battle-system]]).
- Bingo Matutino con racha de 7 días.
- Developer Products y Game Passes listos para conectar ([[monetization-and-growth]]).
- 19 tests automáticos de la lógica (`lune run tests/run.luau`).
