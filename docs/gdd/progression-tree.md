# Progression Tree

Relacionado: [[core-gameplay-loop]], [[economy-systems]]

## Niveles
- XP necesaria para subir del nivel `N` al `N+1`: `ExperiencePerLevel × N` (configurable en `GameConfig.Economy`).
- La XP sobrante se conserva al subir de nivel; varios niveles pueden subirse en una sola ganancia.

| Nivel | XP para el siguiente |
|---|---|
| 1 | 100 |
| 2 | 200 |
| 3 | 300 |
